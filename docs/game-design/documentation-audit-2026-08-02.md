# Game Design Documentation Audit

Date: 2026-08-02

## Scope

This audit covers every Markdown document in `docs/game-design/decisions/` and `docs/game-design/systems/`:

- 8 GDDRs, plus the GDDR template, index, authoring guide, and review checklist
- 13 System documents, plus the System template, index, and authoring guide

The glossary and the current gameplay implementation were inspected only where needed to validate terminology, implementation-status claims, or missing documentation.

## Summary

- All 8 GDDRs contain the mandatory `Status`, `Context`, `Decision`, `Pros`, and `Cons` sections.
- All 13 System documents contain the mandatory `Purpose`, `Core Concepts`, `Rules`, and `Potential Flaws` sections.
- Both indexes contain every current numbered document, and every Markdown link resolves.
- The missing `013` System number is intentional. Cloaking was merged into `010-fleets`; no replacement `013` document is needed.
- The main problems are conflicting rules, missing resolution details, incomplete catalogues, and insufficient distinction between implemented behavior and planned design.

Mark the `Fix?` checkbox for each finding that should be addressed.

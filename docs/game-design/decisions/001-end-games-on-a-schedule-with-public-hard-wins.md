# End games on a schedule with public hard wins

## Status

Planned

## Context

The game needs to give players enough time to invest in and develop an empire, while still guaranteeing that each game ends. It should not reward a player merely for staying in a game indefinitely.

Legacy measures an empire's impact on the galaxy and is the normal way to determine the winner. Some achievements may nevertheless make a winner so clear that continuing the game has no value.

## Decision

Every game has a fixed duration that players know before it starts. If the scheduled end is reached, the empire with the most legacy wins.

A predefined public hard-win achievement may end the game earlier. Its requirements must be sufficiently difficult and conclusive that completing it clearly establishes one empire as the winner. The game ends immediately when that achievement resolves.

There are no shared victories and no minimum-time gate for hard wins. Individual hard-win achievements are designed separately.

## Consequences

Players can plan around a known maximum game length and have time to develop their empires. The fixed deadline ensures that every game reaches a result, even when no empire achieves an exceptional victory.

Legacy remains valuable throughout the game because it decides ordinary endings. Public hard wins create an alternate path to victory, but their requirements must be demanding enough to avoid abrupt or cheap endings.

Future design work must define specific hard-win achievements and the sources of legacy points. Those achievements need clear public progress and a single winning empire.

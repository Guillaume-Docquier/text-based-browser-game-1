# Asymmetric Play

## Status

Planned

- [ ] Political Regimes
- [ ] Regimes Changes

## Context

We want the game to be replayable and make multiple strategies viable. Most strategy games achieve this via a starting Race, Faction or Class.

## Decision

At the start of the game, players will choose their Political Regime. A Political Regime will affect the cost of certain Actions and their efficiency. Some Regimes might be able to play a lot of macro actions, but only a few micro actions. Some might have all actions be cheap, but not effective. Some might go beyond this and allow multiple alignments and switch between them, etc.

The Regime is something that can change during the game, but at a steep cost.

## Pros

- Each Regime changes the way the player plays
- Each Regime changes the way players interact
- Easy to imagine different Regimes

## Cons

- Actions will have to be balanced vs each Regime

# Legacy As Win Condition

## Status

Planned

- [ ] Legacy scoring

## Context

Most space strategy games are conquest games, where everything devolves into having the strongest army to eliminate other players.

This limits the kinds of cooperation that can happen.

This prevents all game mechanics that can be nullified by having your empire destroyed.

## Decision

"Legacy" will be the game's win condition. Your Legacy will be defined as the impact you had on the course of the game.

There will be Legacy Projects or Institutions, which will be large undertakings that fundamentally change how the game is played.

For example:

- Dyson Sphere: Energy is free and infinite
- Science Archives: Empires can share science advancements with all other empires in the game
- Closed Borders: Empires have explicit borders and gain full vision over their territory
- Imperium Coin: Empires can now use a common currency for all trade

Each of these projects changes how the game is played by adding global mechanics. The project's sponsor and the contributors will gain Legacy points via the project's completion.

This encourages collaboration with your enemies. By contributing to a project, you enable it, but you also limit how much points your opponents will get compared to you. Some projects might also highly benefit your strategy even if you don't contribute to them.

There will be other ways to build your Legacy. Legacy Projects should be a strategic choice that balance investments and rewards, not an obvious "whichever you do will win you the game". We want players to build an empire and the Legacy Projects that support it if it fits their strategy. It should be possible to lose because you invested in the wrong Legacy Project or at the wrong time.

Conquest might still be part of the game. If it is, it should be very hard to achieve and should mostly be a strategic investment. It might be worth it to conquer a few key planets, but it should not be viable to eliminate a player.

War will be more about taxing other players or restricting certain actions, not about gaining their territory and preventing them from playing.

## Pros

- Original concept
- Encourages cooperation with all players, even your enemies
- Makes each game unique because you don't know which legacy projects will be achieved
- Modular design, each game could pick and choose which Legacy Projects are available, and adding more should be relatively easy

## Cons

- Might be simplistic if there aren't enough Legacy Project options
- Might devolve into having the best economy if the Legacy Projects only rely on having resources

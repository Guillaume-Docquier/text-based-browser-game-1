# `PlanetSurface` requirements

Next ID number: 0004

## Prefixes

| ID   | Stands for              |
| ---- | ----------------------- |
| SURF | Planet surface display. |

## Requirements

| ID        | Requirement                                                                                                                                                                                                              |
| --------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| SURF-0001 | When the player reloads or reopens a surface, when building records arrive in a different order, or when a building occupies an empty hex, all existing hexes retain their positions relative to the center.             |
| SURF-0002 | When a player inspects a trade center, its dedicated art and income per turn identify the building, and after resolution its owner can see the increased balance.                                                        |
| SURF-0003 | When a planning turn is open, the owner of a planet at turn start can use its existing command center to select a constructible building and an empty surface hex. A command center cannot be selected for construction. |

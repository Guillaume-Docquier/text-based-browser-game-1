# Monitor Blocked Issues

1. Read the current `Status` options and scan every page of [GitHub project 7](https://github.com/users/Guillaume-Docquier/projects/7). Review open, non-archived GitHub issues whose project status is `Blocked`. Use an authenticated GitHub tool with Projects access. With GitHub CLI, use `gh api graphql --paginate` to query `user(login: "Guillaume-Docquier").projectV2(number: 7).items`, passing `$endCursor` to `after` and requesting `pageInfo { hasNextPage endCursor }`. Read `isArchived`, the issue state, and `fieldValueByName(name: "Status")` for each item. The [GitHub Projects API guide](https://docs.github.com/en/issues/planning-and-tracking-with-projects/automating-your-project/using-the-api-to-manage-projects) shows how to look up the project and field IDs.
2. Read the issue and relevant comments to identify each upstream blocker. Follow links to upstream issues, pull requests, release notes, or package artifacts. Confirm from primary sources that the fix covers the reported blocker and is already available in a form Cosmic Empires can use. Check the project's dependency or deployment requirements when they affect availability. An unreleased fix qualifies only if Cosmic Empires can already use it through a supported method. Keep the issue in `Blocked` when evidence is unclear or another blocker remains.
3. Immediately before updating, confirm the item is still open, non-archived, in project 7, and set to `Blocked`. Set only its project `Status` to the current `Todo` option. Resolve the project, project-item, field, and option IDs from GitHub. Update the field with `updateProjectV2ItemFieldValue` or `gh project item-edit --id <item-id> --project-id <project-id> --field-id <status-field-id> --single-select-option-id <todo-option-id>`. Read back the status before reporting success. If an update fails or its result is unclear, read back the current status before any retry.
4. Report each verified move with the issue URL and a link to the upstream fix or release. Report access failures and unclear blockers that need review. If the scan succeeds and finds no verified moves, say so briefly.
